### 새로운 기회!

회사에서 작은 사내 스터디를 시작하게 되었다. 인원은 5명으로 1일 1커밋과 주 1회 블로그 업로드를 규칙으로 정했다. 하지만 내가 운영 중이던 블로그는 정말 구린 상태...ㅎㅎ 이전부터 기록을 제대로 해보고 싶은 생각이 있어서 다양한 플랫폼을 이용해봤지만 딱 마음에 드는 게 없었고, 현실에 타협해서 구축은 나중으로 미루고 있었지만 이번 기회에 블로그 구축부터 몇 회의 블로그 업로드를 해결할 수 있는 기회를 갖게 됐다. 😊

#### 나의 유목민 생활

지금 까지 다양한 플랫폼들을 이용해서 블로그를 작성했었지만 정말 마음에 든다 싶은 플랫폼을 찾는건 쉽지가 않았다. 혹시나 내글이 선택에 도움이 될까 싶어서 장단점을 적어보면 이렇다.

1. 벨로그(Velog)
    - 심플하고 직관적이다. 마크다운 지원이 너무 좋고 글 작성 시 바로 옆에 어떻게 작성될지 보이는 점이 큰 장점이지만 카테고리 기능이 없고 커스텀불가능...ㅠ 
2. Medium
    - 디자인이 깔끔하다. 커스터마이징이 불가하다는 단점, 코드 지원이 빈약

3. 브런치
   - 작가가 되고싶진 않음

4. WordPress
   - GUI로 커스텀이 쉽고 플러그인 방식으로 추가 커스텀은 가능하지만 유료로 안쓰면 좀 힘듬ㅠ 이걸로 옮겼다가 금방 포기
  
5. 티스토리
   - 너무 잘써왔지만 스킨적용하고 커스텀하는 과정에서 맘에 드는게 없음. 마크다운은 있으나마나함.

### 그럼 뭐가 있을까?

깃헙에서 제공하는 깃헙 페이지를 이용해서 서버나 DB 구축 없이 쉽게 웹페이지를 만들 수 있다. 레포지토리에 저장된 HTML을 실제 웹페이지처럼 서비스 가능하게 만들어주는데 나는 이걸 이용하려고 한다. 다양한 프레임워크와 함께 사용해서 자유롭게 커스터마이징이 가능하다. 

1. Jekyll (Ruby)
   - 장점: 설정이 간단하고 GitHub Pages와의 연동이 쉬움.
   - 단점: 속도가 느리고, 대규모 사이트에 적합하지 않음.

2. Gatsby (JavaScript/React)
   - 장점: 성능이 뛰어나고, 많은 플러그인과 테마 지원.
   - 단점: 설정이 복잡하고, 초기 설정에 시간이 많이 걸림.

3. Hexo (JavaScript)
   - 장점: 빠르고, 마크다운 지원이 훌륭함.
   - 단점: 플러그인 및 테마의 다양성이 제한적임.
   - 
4. Hugo (Go)
   - 장점: 매우 빠른 빌드 속도와 쉬운 설정.
   - 단점: 테마와 플러그인이 상대적으로 적음.

5. Next.js (JavaScript/React)
   - 장점: React 기반으로, SEO 최적화와 서버 사이드 렌더링 지원.
   - 단점: 복잡한 설정과 상대적으로 느린 빌드 속도.

6. VitePress (JavaScript/Vue)
   - 장점: Vue 기반으로, 빠른 빌드 속도와 쉬운 설정.
   - 단점: 기능이 제한적이고, 커뮤니티와 생태계가 상대적으로 작음.

### Docusaurus

Docusaurus는 정적 사이트 생성기이다. 빠른 클라이언트 측 탐색을 갖춘 단일 페이지 애플리케이션을 빌드하여 React의 모든 기능을 활용하여 사이트를 대화형으로 만든다. 기본 제공 문서화 기능을 제공하지만 모든 종류의 사이트(개인 웹사이트, 제품, 블로그, 마케팅 랜딩 페이지 등)를 만드는 데 사용할 수 있다.

[문서 보기](https://docusaurus.io/ko/)

- Docusaurus의 주요 기능
  
  - 🎯 SEO 친화적:
    - 모든 접근할 수 있는 경로에 대한 HTML 파일을 만들어준다.
    - 페이지별 SEO를 통해 사용자가 당면한 문제 해결에 필요한 공식 문서에 바로 도달할 수 있도록 도와준다.

  - 📝 MDX 제공:
    - 마크다운 문서 내에 JSX와 리액트로 동적인 컴포넌트를 작성할 수 있다.
    - 라이브 에디터를 사용해 사용자가 즉시 코드를 실행해볼 수 있다.

  - 🔍 검색:
    - 전체 사이트를 검색할 수 있다.

  - 💾 문서 버전 관리:
    - 프로젝트 릴리스와 문서를 동기화 상태로 유지하는 데 도움이 된다.

  - 🌍 국제화(i18n):
    - 여러 지역으로 사이트를 번역할 수 있다.
