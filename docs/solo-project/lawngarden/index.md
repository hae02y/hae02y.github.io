## 1. 프로젝트 개요

<aside>

**Lawn Garden**

---

- **소개** : Clone coding - 게시판 및 CRUD 구현
- **기간** : 2023.08.04 ~ 2023.08.23 (2주) 
- **인원** : Backend 1명, Frontend 1명 (총 2명)
- [🔗 레포지토리 링크](www.naver.com)

### 핵심 기술 스택

- **Backend:** Java, Spring Boot, Spring Security, JPA, Hibernate
- **Database:** MySQL, AWS RDS
- **CI/CD & DevOps:** Docker, AWS EC2, S3, Github Actions, CodeDeploy
- **ETC :** JWT, OAuth 2.0 (Google), Google SMTP


### 개인 기여

- ##### **Backend (100%)**
    - **DB 설계 및 API 문서 작성 (100%)**
        - MySQL 데이터베이스 설계 및 테이블 구조 정의
        - 각 API에 대한 명세서 작성 및 문서화
    - **질문 CRUD 구현 (100%)**
        - 질문 등록, 조회, 수정, 삭제 기능을 제공하는 API 개발
        - JPA를 활용하여 데이터 저장 및 조회 최적화
    - **답변 CRUD 구현 (100%)**
        - 답변 등록, 조회, 수정, 삭제 기능을 제공하는 API 개발
        - 답변과 질문 간의 관계 설정 및 데이터 연관 처리
    - **태그 CRUD 구현 (100%)**
        - 태그 등록, 조회, 수정, 삭제 기능을 제공하는 API 개발
        - 질문 및 답변에 태그 기능 적용
    - **CI/CD (AWS EC2 + Github Action) (80%)**
        - Github Actions를 활용한 자동 배포 파이프라인 구축
        - AWS EC2를 활용하여 서비스 배포 및 운영 환경 구성
    - **MySQL DB 서버 연동 (AWS RDS 사용) (100%)**
        - AWS RDS를 이용하여 MySQL 데이터베이스 서버 설정 및 연동
        - 데이터베이스 연결 설정 및 성능 최적화 작업 수행    

- #### **Soft Skill(30%)**
  - **팀장 역할 수행(100%)**
    - Frontend 3명, Backend 3명이서 함께 진행한 프로젝트에서 팀장 역할 수행
